## 1. 개요

### 1.1 목적

본 기준정의서는 CalZero 시스템에서 수행하는 모든 캘리브레이션의 **품질 기준, 합격/불합격 임계값, 데이터 구조, 환경 요구사항**을 정의한다. 모든 캘리브레이션 판정은 본 문서의 기준에 따라 수행한다.

### 1.2 적용 범위

- CalZero v0.3.0에서 지원하는 모든 캘리브레이션 유형
- 액추에이터(6축 조인트), 카메라(Intrinsic/Extrinsic/Hand-Eye), 리플레이 테스트
- 학습 데이터 분석
- 향후 센서(Force/Torque, IMU) 캘리브레이션 (placeholder)

### 1.3 용어 및 약어

| 약어 | 정의 |
|------|------|
| **RMS** | Root Mean Square (제곱평균제곱근) |
| **σ** | 표준편차 (Standard Deviation) |
| **px** | pixel (화소) |
| **mm** | millimeter (밀리미터) |
| **step** | 모터 엔코더 스텝 (0~4095 범위) |
| **DOF** | Degrees of Freedom (자유도) |
| **FK** | Forward Kinematics (순기구학) |
| **TCP** | Tool Center Point (공구 중심점) |
| **URDF** | Unified Robot Description Format |
| **JWT** | JSON Web Token |
| **KST** | Korea Standard Time (UTC+9) |

### 1.4 관련 문서

| 문서 | 번호 | 설명 |
|------|------|------|
| 캘리브레이션 절차서 | CZ-PROC-001 | 단계별 작업 절차 |

## 2. 환경 기준

캘리브레이션 품질은 환경 조건에 직접적으로 영향을 받는다. 아래 기준을 만족하는 환경에서 캘리브레이션을 수행해야 한다.

### 2.1 온도 조건

| 항목 | 기준값 | 허용 범위 |
|------|--------|----------|
| 실내 온도 | 20°C (기준) | 18~25°C |
| 온도 변화율 | ≤ 2°C/h | 캘리브레이션 진행 중 |
| 안정화 대기 | ≥ 30분 | 장치 이동 또는 환경 변경 후 |

**근거**: 모터 및 기구부의 열팽창이 캘리브레이션 결과에 영향을 미친다. 급격한 온도 변화 시 기구부 치수가 변하여 반복정밀도가 저하된다.

### 2.2 습도 조건

| 항목 | 기준값 |
|------|--------|
| 상대습도 | 40~60% RH |
| 결로 | 발생 금지 |

### 2.3 진동 기준

| 항목 | 기준 |
|------|------|
| 캘리브레이션 중 | 외부 진동원 제거 |
| 인접 장비 | 캘리브레이션 중 가동 중지 권장 |
| 바닥 조건 | 안정된 바닥면 (방진 패드 권장) |

### 2.4 조명 조건 (카메라 캘리브레이션)

| 항목 | 기준 |
|------|------|
| 조도 | 300~1000 lux (균일 분포) |
| 광원 타입 | 간접 조명 (확산광 권장) |
| 금지 조건 | 직사광선, 점멸 조명(형광등 flicker), 강한 반사 |
| 체커보드 | 표면 반사 없는 무광 인쇄 |

```
  name:             string       (필수, 고유 식별명)

  firmware_version: string       (선택)
  created_at:       ISO8601      (자동, KST)
  updated_at:       ISO8601      (자동, KST)
}
```

**입력 검증 규칙**:
- `name`, `location`, `manager`: 필수 (빈 값 불가)
- `ip_address`: IPv4 형식 (`^(\d{1,3}\.){3}\d{1,3}$`)
- `port`: 정수, 1~65535 범위

### 3.3 장치 상태 정의

| 상태 | 의미 | 시각적 표현 | 캘리브레이션 |
|------|------|------------|:-:|

| `offline` | 연결 끊김 또는 미사용 | 회색 원 | 불가 |
| `maintenance` | 점검/수리 중 | 앰버(호박색) 원 | 불가 |
| `error` | 오류 발생 | 로즈(빨간색) 원 | 불가 |

## 4. 액추에이터 캘리브레이션 기준

> 관련 절차: [절차서 4장](./CALIBRATION_PROCEDURE.md#4-액추에이터-캘리브레이션-절차)

### 4.1 조인트 정의 (6축)

SO101 로봇 암은 6개 조인트로 구성된다:

| # | 조인트명 | 모터 ID | 역할 | 색상 코드 |
|---|---------|---------|------|----------|
| 1 | `shoulder_pan` | 1 | 어깨 회전 (좌/우) | Cyan `#00d4ff` |
| 2 | `shoulder_lift` | 2 | 어깨 들기 (상/하) | Red `#ff6b6b` |
| 3 | `elbow_flex` | 3 | 팔꿈치 굽힘 | Teal `#4ecdc4` |
| 4 | `wrist_flex` | 4 | 손목 굽힘 | Yellow `#ffd93d` |
| 5 | `wrist_roll` | 5 | 손목 회전 | Purple `#a855f7` |
| 6 | `gripper` | 6 | 그리퍼 열기/닫기 | Orange `#ff8c00` |

### 4.2 파라미터 정의

| 파라미터 | 단위 | 범위 | 설명 |
|---------|------|------|------|
| `homing_offset` | step | -2048 ~ +2047 | 홈 위치 오프셋. 기준값(2047)으로부터의 편차 |
| `range_min` | step | 0 ~ 4095 | 조인트 최소 가동 위치 |
| `range_max` | step | 0 ~ 4095 | 조인트 최대 가동 위치 |
| `drive_mode` | - | 0 또는 1 | 모터 구동 방향 모드 |
| `id` | - | 1 ~ 6 | 모터 식별 번호 |

**상수**:
- 홈 위치 기준값 (homing constant): **2047**
- 엔코더 분해능: **4096 steps/revolution** (12-bit)
- 1 step = 360° / 4096 ≈ **0.0879°**

### 4.3 통계적 품질 기준

히스토리 데이터에 대한 통계 분석을 통해 이상치를 탐지한다.

**전제 조건**: 최소 **5회** 이상의 캘리브레이션 데이터가 있어야 통계적으로 유효하다. 5회 미만인 경우 "참고용"으로만 활용한다.

**편차 계산**:
```
deviation = |current_value - mean| / standard_deviation
```

**판정 기준**:

| 등급 | 조건 | 확률 (정규분포) | 시각적 표현 | 조치 |
|------|------|:-------------:|------------|------|
| 정상 | deviation < 2σ | ~95.4% | 기본 | 추가 조치 없음 |
| 경고 | 2σ ≤ deviation < 3σ | ~4.3% | ⚠️ 앰버 | 프로세스 재확인, 모니터링 강화 |
| 위험 | deviation ≥ 3σ | ~0.3% | 🚨 로즈 | **즉시 재측정** 권장 |

### 4.4 최소 데이터 수

| 분석 유형 | 최소 데이터 수 | 비고 |
|-----------|:------------:|------|
| 통계 분석 (σ 기반) | 5회 | 미만 시 "참고용" 표시 |
| 트렌드 분석 | 3회 | 추이 확인 최소 수 |
| 비교 분석 | 2회 | 두 캘리브레이션 간 비교 |

### 4.5 캘리브레이션 비교 기준

두 캘리브레이션 결과를 비교할 때:

| 조건 | 판정 | 표시 |
|------|------|------|
| \|차이\| ≤ 30 steps | 정상 | 녹색 |
| \|차이\| > 30 steps | **이상** | 빨간색 |

30 steps ≈ 30 × 0.0879° ≈ **2.64°**

### 4.6 팔 길이 기준 선형 오차 공식

330mm 팔 길이에서의 End-Effector 위치 오차 추정:

```
error_mm = 330 × std_steps × (π / 180) × (360 / 4096)
```

| 변수 | 의미 |
|------|------|
| `330` | 팔 길이 (mm) |
| `std_steps` | homing_offset의 표준편차 (step 단위) |
| `π / 180` | degree → radian 변환 |
| `360 / 4096` | step → degree 변환 |

**계산 예시**:
- std = 20 steps
- error = 330 × 20 × π/180 × 360/4096 ≈ **1.01 mm**

## 5. 카메라 캘리브레이션 기준

> 관련 절차: [절차서 5~7장](./CALIBRATION_PROCEDURE.md#5-카메라-intrinsic-캘리브레이션-절차)

### 5.1 체커보드 사양

| 타입 | 열 × 행 | 기본 사각형 크기 | 파일 |
|------|---------|:---------------:|------|
| Standard 9×6 | 9 × 6 | 24.0 mm | `standard_9x6.pdf` |
| 14×8 | 14 × 8 | 17.4 mm | `14x8.pdf` |

**필수 사항**:
- A4 용지에 **100% 원본 크기** 인쇄 (축소/확대 금지)
- 인쇄 후 **실제 사각형 크기를 3회 실측**하여 평균값 사용
- 평평한 보드에 주름 없이 부착
- 무광 표면 (반사 방지)

### 5.2 이미지 요구사항

| 항목 | 최소 | 권장 | 비고 |
|------|:----:|:----:|------|
| 이미지 수 | 3장 | **10장 이상** | 많을수록 안정적 |
| 지원 형식 | JPG, PNG | - | - |
| 각도 다양성 | 3방향 이상 | 5방향 이상 | 정면, 좌/우, 상/하 기울기 |
| 거리 다양성 | 2종 이상 | 3종 이상 | 가까이, 중간, 멀리 |
| 프레임 내 위치 | 중앙 | 전체 영역 | 가장자리 포함 |
| 초점 | 선명 | - | 흐린 이미지 제외 |
| 체커보드 크기 | 프레임의 1/4 이상 | 1/3 ~ 2/3 | 너무 작으면 검출 어려움 |

### 5.3 Intrinsic 품질 기준

**RMS Error (재투영 오차)**:

| 등급 | RMS Error | 판정 | 색상 | 조치 |
|------|:---------:|------|------|------|
| 우수 | < 0.5 px | 합격 | 에메랄드 | 결과 저장 |
| 양호 | 0.5 ~ 1.0 px | 조건부 합격 | 앰버 | 결과 저장, 추가 이미지 고려 |
| 부적합 | > 1.0 px | **불합격** | 로즈 | 이미지 교체/추가 후 재실행 |

**출력 데이터**:
- **Camera Matrix (K)**: 3×3 행렬
  ```
  [fx   0  cx]
  [ 0  fy  cy]
  [ 0   0   1]
  ```
  - fx, fy: 초점거리 (pixel), 양수 값
  - cx, cy: 주점 (이미지 중심 근처)
- **Distortion Coefficients**: [k1, k2, p1, p2, k3]
  - k1, k2, k3: 방사 왜곡 계수
  - p1, p2: 접선 왜곡 계수

### 5.4 Extrinsic 품질 기준

**Reprojection Error**:

| 등급 | Error | 판정 |
|------|:-----:|------|
| 우수 | < 0.5 px | 합격 |
| 양호 | 0.5 ~ 1.0 px | 조건부 합격 |
| 부적합 | > 1.0 px | 불합격 |

**출력 데이터**:
- Rotation Vector [rx, ry, rz] (radian, axis-angle)
- Translation Vector [tx, ty, tz] (mm)
- Rotation Matrix (3×3)

**전제 조건**:
- Intrinsic 캘리브레이션이 합격 상태여야 한다
- 동일한 체커보드 타입을 사용해야 한다

### 5.5 Hand-Eye 캘리브레이션 기준

**타입 정의**:

| 타입 | 카메라 위치 | 변환 관계 | 카메라 |
|------|------------|----------|--------|
| Eye-in-Hand | 로봇 엔드이펙터 | T_camera_to_tool | `wrist_cam` |
| Eye-to-Hand | 외부 고정 | T_camera_to_base | `front_cam` |

**입력 요구사항**:

| 항목 | 최소 | 권장 |
|------|:----:|:----:|
| 포즈 수 (이미지 + 조인트 데이터) | 3 | **10 이상** |
| 데이터 매칭 | 이미지 수 = 조인트 데이터 수 (필수) | |
| URDF 파일 | 1개 (필수) | |

**품질 기준**:
- Reprojection Error < 1.0 px: 합격
- Reprojection Error ≥ 1.0 px: 불합격

**출력 데이터**:
- Transformation Matrix (4×4 동차 변환)
- Translation [tx, ty, tz] (mm)
- Rotation Matrix (3×3)
- Rotation Euler [roll, pitch, yaw] (degrees)

### 5.6 알고리즘 파라미터

| 파라미터 | 값 | 설명 |
|---------|:--:|------|
| Corner Sub-Pixel 반복 횟수 | 30 | `cv2.cornerSubPix` termination |
| Corner Sub-Pixel 정밀도 (ε) | 0.001 | 수렴 기준 |
| 탐색 윈도우 크기 | 11 × 11 px | 코너 세분화 영역 |
| 캘리브레이션 알고리즘 | Zhang's Method | `cv2.calibrateCamera` |
| 포즈 추정 알고리즘 | solvePnP | `cv2.solvePnP` |

## 6. 리플레이 테스트 기준

> 관련 절차: [절차서 8장](./CALIBRATION_PROCEDURE.md#8-리플레이-정확도-테스트-절차)

### 6.1 테스트 프로토콜

- 테스트 방식: **6-포지션 반복 정밀도 테스트**
- 로봇이 6개의 사전 정의된 목표 위치로 이동
- 각 위치에서 실제 도달점과 목표점의 3D 오차를 측정

### 6.2 오차 계산

**3D 유클리드 거리**:
```
distance = √(error_x² + error_y² + error_z²)
```

**통계 지표**:
| 지표 | 계산 |
|------|------|
| `avg_error` | 6개 포지션 distance의 산술 평균 |
| `max_error` | 6개 포지션 distance의 최대값 |

### 6.3 합격 기준

평균 오차(avg_error) 기준:

| 등급 | 평균 오차 | 색상 | 판정 | 조치 |
|------|:---------:|------|------|------|
| 정상 | ≤ 3 mm | 에메랄드 | 합격 | 추가 조치 없음 |
| 주의 | 3 mm < ~ ≤ 5 mm | 앰버 | 주의 | 원인 조사, 모니터링 강화 |
| 재캘리브레이션 | > 5 mm | 로즈 | **불합격** | 즉시 액추에이터 재캘리브레이션 |

**기본 임계값**:
- `replay_threshold_normal`: 3 mm
- `replay_threshold_warning`: 5 mm
- 사용자 조정 가능 (CalZero 설정, localStorage에 저장)

### 6.4 트렌드 분석 기준

| 항목 | 기준 |
|------|------|
| 최소 데이터 수 | 2회 이상 |
| 표시 범위 | 최근 10회 |
| 분석 지표 | 전체 평균, 최저(최고 품질), 최고(최저 품질) 오차 |
| 악화 경고 | 연속 3회 증가 추세 시 예방적 재캘리브레이션 권장 |

## 7. 학습 데이터 분석 기준

> 관련 절차: [절차서 9장](./CALIBRATION_PROCEDURE.md#9-학습-데이터-분석-절차)

### 7.1 구간 정의

각 조인트의 `range_min` ~ `range_max` 범위를 기준으로 데이터 분포를 분석한다:

| 구간 | 범위 | 색상 | 위험도 | 설명 |
|------|------|------|:------:|------|
| **위험 구간** | 양끝 0~5% | 빨간색 (`#ff5555`) | 높음 | 물리적 한계 근처, 모터 손상 위험 |
| **경고 구간** | 양끝 5~10% | 주황색 (`#ff8844`) | 중간 | 주의 필요, 가동 한계 접근 |
| **안전 구간** | 10~90% | 기본색 | 낮음 | 정상 작동 범위 |

**구간 경계 계산**:
```
range = range_max - range_min
danger_boundary = range × 0.05
warning_boundary = range × 0.10
```

### 7.2 히스토그램 설정

| 파라미터 | 값 |
|---------|:--:|
| bin 수 | 50 |
| 범위 | range_min ~ range_max (조인트별) |

### 7.3 정규화 범위

학습 데이터의 action/state 값은 정규화된 형태로 저장될 수 있다:
```
정규화 범위: [-100, 100]
역변환: raw_value = ((normalized + 100) / 200) × calibRange + calibMin
```

### 7.4 홈 위치 기준값

- homing constant: **2047**
- 히스토그램에 기준선으로 표시
