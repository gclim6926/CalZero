# 로봇 도입 체크리스트 (Robot On-boarding Checklist)

> CalZero 기반 로봇 도입·캘리브레이션·검증 전 과정 체크리스트입니다.
> 각 항목의 "업체 제공 문서"는 공급업체에 요청해야 하는 자료를 의미합니다.

## Pre단계. 초기 미팅 / 도입 검토

## Post단계. Sim-to-Real 검증 (Sim-to-Real Validation)

시뮬레이터에서 학습한 AI 정책(Policy)이 실제 로봇에서 의도한 대로 동작하는지를 체계적으로 검증하는 단계입니다. Sim과 Real 사이의 Domain Gap을 계층적으로 측정하고, 도메인 랜덤화 범위와 파인튜닝 전략을 데이터 기반으로 조정합니다.

### Post-1. 시뮬레이터 모델 정합성 (Simulation Model Fidelity)

업체 제공 모델 파일이 실제 로봇을 정확히 표현하는지 기본 수치부터 확인합니다.

| No. | 항목                      | 설명                                                                          |      업체 제공 문서      | 확인 |
| --- | ------------------------- | ----------------------------------------------------------------------------- | :----------------------: | :--: |
| 1   | 관절 범위 일치 여부       | 모델 파일의 joint limit과 CalZero 실측 range 비교. 오차 ±5% 이내 권장        |  URDF / MJCF 모델 파일  |      |
| 2   | 링크 길이 / 질량 정확도   | 모델 파일의 링크 길이와 질량 값이 실제와 일치하는지. 오차 ±2mm 이내 권장     |   CAD 도면 / 모델 파일   |      |
| 3   | 홈 포지션 일치 여부       | Sim에서 모든 관절값 0일 때의 자세가 실로봇 홈 포지션과 동일한지               |   캘리브레이션 매뉴얼   |      |
| 4   | 강성/감쇠 파라미터 유효성 | 시뮬레이터에 설정한 actuator stiffness/damping 값이 실제 관절 응답과 유사한지 | 시뮬레이터 파라미터 문서 |      |
| 5   | 충돌 메시 정확도          | 시뮬레이터 모델의 collision geometry가 실제 로봇 외형과 일치하는지            |   Collision 메시 파일   |      |

### Post-2. 운동학/역학 매칭 (Kinematics & Dynamics Matching)

같은 명령을 주었을 때 Sim과 Real의 동작이 얼마나 일치하는지 정량 측정합니다.

| No. | 항목                  | 설명                                                                                                | 업체 제공 문서 | 확인 |
| --- | --------------------- | --------------------------------------------------------------------------------------------------- | :------------: | :--: |
| 6   | 순운동학 오차         | 동일 joint angle 시 Sim과 Real의 end-effector 위치 차이. 위치 오차 ±5mm, 자세 오차 ±2° 이내 권장 |       —       |      |
| 7   | 속도/가속도 응답 일치 | 동일 velocity 명령에 대한 관절 속도 프로파일 비교. 최종값 오차 ±10%                                |       —       |      |
| 8   | 토크 / 중력 보상 동작 | 동일 자세에서 Sim과 Real의 관절 토크 값 비교. 오차 ±15% 이내 권장                                  |       —       |      |
| 9   | 마찰 / 백래시 특성    | 저속 왕복 동작에서 encoder 편차 측정. Domain Randomization 범위 설정에 반영                         |       —       |      |

### Post-3. 센서 데이터 매칭 (Sensor Data Validation)

Sim의 가상 센서 출력과 실제 센서 출력이 일치하는지 확인합니다.

| No. | 항목                      | 설명                                                                         | 업체 제공 문서 | 확인 |
| --- | ------------------------- | ---------------------------------------------------------------------------- | :------------: | :--: |
| 10  | 카메라 내부 파라미터 일치 | Sim 렌더 카메라의 fx/fy/cx/cy와 CalZero 실측값 비교. 초점거리 오차 ±5% 이내 |       —       |      |
| 11  | 이미지 도메인 갭          | Sim 렌더링 이미지와 실제 카메라 이미지의 색상/밝기/텍스처 차이 확인          |       —       |      |
| 12  | 힘/토크 센서 제로 오프셋  | 실로봇 F/T 센서의 zero drift 여부 확인                                       |       —       |      |
| 13  | 관절 엔코더 노이즈 수준   | 정지 상태에서 encoder raw 값 100회 측정 후 표준편차 확인                     |       —       |      |

### Post-4. 정책 전이 검증 (Sim-to-Real Policy Transfer)

Sim에서 학습한 policy를 실로봇에 배포했을 때의 성능을 측정하고 개선 방향을 결정합니다.

| No. | 항목                      | 설명                                                                |  업체 제공 문서  | 확인 |
| --- | ------------------------- | ------------------------------------------------------------------- | :--------------: | :--: |
| 14  | 제로샷 전이 성공률        | fine-tune 없이 Sim-only policy를 실로봇에 배포했을 때 태스크 성공률 |        —        |      |
| 15  | 도메인 랜덤화 설정 적정성 | Sim 학습 시 사용한 DR 범위가 실제 환경 변동 범위를 커버하는지       |        —        |      |
| 16  | 파인튜닝 후 성능 향상     | 실로봇 데모 데이터로 fine-tune 후 성공률 변화                       |        —        |      |
| 17  | 데이터 포맷 호환성        | Sim 합성 데이터와 실로봇 수집 데이터의 포맷이 동일하게 처리되는지   | 데이터 포맷 문서 |      |
| 18  | 이상 동작 자율 복구 확인  | Sim에서 학습된 recovery policy가 실로봇에서도 동작하는지            |        —        |      |
